## vi

太古から利用されるエディタです.
vim ではありません. vi です.
普段遣いするならどう考えても vim なり nano なりを利用した方が賢明ですし, 最近の Linux ではほぼ見かけることはありません.
太古のシステムや最小構成を必須とするようなケースがある場合に限り記憶しましょう.

### モード

vi ではコマンドモードとインサートモードがあります.
vim のようなノーマルモードやビジュアルモードはありません.

### インサートモードへの切り替え

| コマンド | 挙動                                                         |
| :------- | :----------------------------------------------------------- |
| `i`      | カーソルの前にテキストを挿入                                 |
| `a`      | カーソルの後にテキストを挿入                                 |
| `I`      | 行頭の最初の文字にカーソルを移動し, その直前にテキストを挿入 |
| `A`      | 行末の最後の文字にカーソルを移動し, その直後にテキストを挿入 |
| `o`      | カーソル下の行に空白行を挿入し, その行でテキストを挿入       |
| `O`      | カーソル上の行に空白行を挿入し, その行でテキストを挿入       |

### コマンドモードで実行可能なコマンド

#### カーソル移動

移動はキーボード右手ホームポジションを 1 つ左から左上下右です.

| コマンド   | 挙動                      |
| :--------- | :------------------------ |
| `h`        | カーソルを 1 文字左へ移動 |
| `j`        | カーソルを 1 文字上へ移動 |
| `k`        | カーソルを 1 文字下へ移動 |
| `l`        | カーソルを 1 文字右へ移動 |
| `0`        | カーソルを行頭へ移動      |
| `$`        | カーソルを行末へ移動      |
| `H`        | 画面の一番上の行頭へ移動  |
| `L`        | 画面の一番下の行末へ移動  |
| `gg`       | ファイルの先頭行へ移動    |
| `G`        | ファイルの最終行へ移動    |
| `nG`, `:n` | ファイルの N 行目へ移動   |
| Ctrl + b   | 1 画面分上へ移動          |
| Ctrl + f   | 1 画面分下へ移動          |

#### ファイル保存

`:wq` と `:x` は異なる挙動を取り, `:x` は変更がない場合はファイルの更新時間を更新しません.

| コマンド | 挙動                                              |
| :------- | :------------------------------------------------ |
| `:q`     | ファイルへ保存せず終了                            |
| `:q!`    | ファイルへ保存せず終了 (確認なし)                 |
| `:w`     | ファイルへ保存する (常に保存)                     |
| `:wq`    | ファイルへ保存して終了 (常に保存)                 |
| `:x`     | ファイルへ保存して終了 (変更のあった場合のみ保存) |
| `ZZ`     | ファイルへ保存して終了 (変更のあった場合のみ保存) |

#### 編集

大体は Yank, Delete, Put の組み合わせです.

| コマンド | 挙動                                     |
| :------- | :--------------------------------------- |
| `x`      | カーソル位置の文字を削除                 |
| `X`      | カーソル位置の直前の文字を削除           |
| `dd`     | 現在の行を削除                           |
| `dw`     | 現在のカーソル位置から次の単語までを削除 |
| `yy`     | 現在の行の内容をバッファにコピー         |
| `p`      | カーソル下の行にバッファの内容を貼り付け |
| `P`      | カーソル上の行にバッファの内容を貼り付け |

各操作はその前に数値を入力することで, その操作回数を指定できます.

- `20x` は 20 文字を削除
- `10yy` は 10 行をコピー
- `5p` は　5 回バッファの内容を貼り付け

#### 検索

| コマンド        | 挙動                                                 |
| :-------------- | :--------------------------------------------------- |
| `/<pattern>`    | カーソル位置から後方に向かってパターンを検索         |
| `?<pattern>`    | カーソル位置から前方に向かってパターンを検索         |
| `n`             | 検索実行後, 次を検索                                 |
| `N`             | 検索実行後, 前を検索                                 |
| `:%s/<A>/<B>`   | パターン A に合致する文字列 1 つをパターン B に置換  |
| `:%s/<A>/<B>/g` | パターン A に合致する文字列すべてをパターン B に置換 |

#### コマンド実行

`:!<command>` を実行することでシェルコマンドを実行できます.
例えば `:!ls` を実行すると, ディレクトリやファイルの一覧を vi を開きながら確認できます.

`:r!<command>` を実行することでシェルコマンドの実行結果をファイル内に挿入できます.
