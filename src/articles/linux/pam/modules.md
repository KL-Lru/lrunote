PAM はどのフェーズとして設定されるかによって実行される処理が変動します.

## 汎用

| フェーズ | PAM モジュール | 内容           |
| :------- | :------------- | :------------- |
| *        | pam_permit     | 常に成功を返す |
| *        | pam_deny       | 常に失敗を返す |

## ログイン認証

| フェーズ | PAM モジュール                    | 内容                                                                                                                                       |
| :------- | :-------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------- |
| auth     | pam_unix                          | 通常のパスワード認証を実行する (/etc/shadow 参照)                                                                                          |
| account  | pam_unix                          | アカウント/パスワードの有効期限を確認する                                                                                                  |
| password | pam_unix                          | 通常のパスワード変更処理を提供する                                                                                                         |
| auth     | pam_ldap                          | LDAP を利用したパスワード認証を実行する                                                                                                    |
| account  | pam_ldap                          | LDAP を利用してアカウント/パスワードの有効期限を確認する                                                                                   |
| password | pam_ldap                          | LDAP を利用したパスワード変更処理を提供する                                                                                                |
| auth     | pam_sss                           | SSSD を利用したパスワード認証を実行する                                                                                                    |
| account  | pam_sss                           | SSSD を利用してアカウント/パスワードの有効期限を確認する                                                                                   |
| password | pam_sss                           | SSSD を利用したパスワード変更処理を提供する                                                                                                |
| auth     | pam_faillock                      | アカウントのロック状態を検証する (preauth) <br> 認証失敗時のカウントを増やす (authfail) <br> 認証成功時にカウントをリセットする (authsucc) |
| account  | pam_faillock                      | auth フェーズ成功終了時に失敗カウンタをリセットする                                                                                        |
| password | pam_pwquality <br> (pam_cracklib) | 脆弱なパスワードの設定を行わせないためのパスワードポリシーを強制する                                                                       |

## ユーザ許可

PAM は認証のフレームワークですが, 一部認可的なモジュールも存在しています.

| フェーズ | PAM モジュール | 内容                                                                                                    |
| :------- | :------------- | :------------------------------------------------------------------------------------------------------ |
| auth     | pam_nologin    | /etc/nologin ファイルがあり, 一般ユーザの場合は拒否する                                                 |
| auth     | pam_securetty  | /etc/securetty ファイルに記載された端末以外からのアクセス, かつ root として認証しようとした場合拒否する |
| auth     | pam_wheel      | wheel 所属のメンバ以外が root として認証しようとした場合拒否する                                        |
| auth     | pam_rootok     | 実行者が root であれば許可する                                                                          |
| auth     | pam_succeed_if | アカウントの属性が条件を満たせば許可する                                                                |
| account  | pam_access     | /etc/security/access.conf ファイルに記載されたユーザがどのホスト/端末からログインできるかを確認する     |
| account  | pam_listfile   | 読み込んだファイルを元に許可 / 拒否リストとして利用して判定する                                         |

## 周辺処理

| フェーズ | PAM モジュール | 内容                                                        |
| :------- | :------------- | :---------------------------------------------------------- |
| auth     | pam_env        | ユーザログイン前に環境変数の初期設定を行う                  |
| session  | pam_env        | ユーザログイン後の環境変数の初期設定を行う                  |
| session  | pam_motd       | ユーザログイン後に /etc/motd の内容をターミナル上に表示する |
| session  | pam_warn       | ユーザログイン / パスワード変更時などでログを出力する       |
